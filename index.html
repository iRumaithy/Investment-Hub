غير مربوط

مزامنة مباشرة باستخدام API Key بصلاحية قراءة فقط. المفاتيح محفوظة في Cloudflare Worker ولا تصل إلى المتصفح.

القيمة والكمية وPnL الرسمية لا تتغير بالسعر اللحظي. مزامنة تلقائية كل 30 ثانية أثناء فتح التطبيق.
تظهر تفاصيل دقة OKX بعد أول مزامنة.
XTB
استيراد يدوي

ارفع تقرير Open Positions الحقيقي من XTB Web بصيغة XLSX أو CSV. لن نعرض أي سهم قبل استيراده من حسابك، ثم نحدّث سعره عبر Twelve Data.

لم يتم استيراد ملف بعد.

غير متصل
