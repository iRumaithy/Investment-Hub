# Investment Hub v2.5.0

## 1) مزامنة OKX أدق وأسرع
- المزامنة الخاصة تتم كل 30 ثانية أثناء فتح التطبيق.
- القيمة الرسمية للمحفظة تأتي من OKX `asset-valuation`.
- الكميات تجمع Trading + Funding + Earn/Savings.
- يتم تفضيل السعر المشتق من بيانات الحساب الخاصة في OKX بدل طلب سعر خارجي لكل أصل.
- Twelve Data يستخدم فقط كـ fallback للأصول الموجودة حصريًا في Funding/Earn عندما لا يوجد سعر من بيانات الحساب الخاصة.
- OKX WebSocket يعرض `marketPrice` فقط ولا يغير `usdValue` الرسمي القادم من المزامنة الخاصة.
- قسم الربط يعرض فحص تطابق: إجمالي OKX الرسمي، مجموع الأصول، Trading، Funding، Earn، والفرق.

## 2) تبويب «السجل»
- تسجيل شراء وبيع للأسهم والعملات الرقمية.
- الحقول: الرمز، الاسم، المنصة، التاريخ، الكمية، سعر الوحدة، الرسوم، الهدف، الملاحظات.
- يدعم البيع الجزئي.
- يمنع بيع كمية أكبر من المسجلة.
- يحسب الربح المحقق بطريقة متوسط التكلفة.
- يحسب الربح غير المحقق للمراكز المفتوحة عند توفر سعر حي من المحفظة.
- يعرض إجمالي المبالغ المستثمرة، الربح المحقق، غير المحقق، ونسبة الصفقات الرابحة.
- بيانات السجل محفوظة في localStorage وتدخل تلقائيًا في النسخة الاحتياطية العامة للتطبيق.
